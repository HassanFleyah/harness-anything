# Example: Weekly report

A user says: “I spend Monday mornings combining sales spreadsheets and emailing a summary to myself.”

HAT asks for sanitized spreadsheets, the desired summary, file locations, reporting period, schedule, email destination, missing or duplicate row handling, available service and permissions, budget, privacy and failure behavior.

The reviewer checks whether the proposed calculations and examples match the user's actual needs. HAT presents the workflow, integration requirements, costs and tests, then waits for approval before building. It does not send email without authorization. The handoff distinguishes tested calculations from an email integration that could not be tested.
